# komebito7-wind-cover — 『こめびと』第7号（テーマ：風）v3.0 表紙アート＆インタラクティブ風紋版画スタジオ

シマダグループ総合冊子『こめびと』第7号 表紙デザインコンテスト（テーマ：「風」／JIS B4ヨコ見開き：右＝表表紙・左＝裏表紙／JPEG 10MB以下）向けの作品展示・5mラック製本検証・手で風を描くネイティブ `3640×2570px` 版画エンジン・実写B4光学クロッパー統合Webスタジオです。

## v3.0 全面再構築の3作品（3640 × 2570 px / sRGB / 10MB以下）

1. **作品①『朝の湯気、窓辺の春風』**（`assets/komebito7_v3_work1_asayuge.jpg` / 1.27 MB）
   - 現代多色木版画×岩絵具ガッシュ調。開け放した朝の窓から白いカーテンがふわりと膨らみ、炊きたての土鍋ごはんの白い湯気が朝の風に乗って横へたなびく至福の数秒間。
2. **作品②『五分間の風を晒す』**（`assets/komebito7_v3_work2_cyanotype.jpg` / 1.43 MB）
   - 日光青写真（サイアノタイプ）。太陽光で5分間露光するあいだに吹いた風が、揺れた稲穂と野草の淡い水色の二重残像となって紙に直接記録されたボタニカル光画。
3. **作品③『風わたる街と窓辺』**（`assets/komebito7_v3_work3_diorama.jpg` / 1.47 MB）
   - 7層の立体切り絵シャドーボックス×夕陽の落ち影。窓辺から吹き出した風が黄金色の棚田、小川の橋を散歩する老夫婦、凧を揚げる子ども、街の屋根へと渡っていく立体風景。

## 主な機能

1. **施設・ホテルラック 5m視認性テスト（B5製本モック3並列）＆全世代進化タイムライン（`v3 ⇄ v2 ⇄ v1`）**
2. **手で風を描くB4版画・日光青写真ジェネレーター（非AI Canvas・引き伸ばしボケなしのネイティブ `3640×2570px` JPEG出力）**
3. **実写カメラ写真 → B4ヨコ（`3640×2570px`・10MB以下）光学クロッパー（外部送信なし）**
4. **v3 決定稿コメント文1タップコピー＆提出チェックリスト**
