# komebito7-wind-cover — 『こめびと』第7号（テーマ：風）v2 ゼロベース刷新 B4見開き表紙スタジオ

シマダグループ総合冊子『こめびと』第7号 表紙デザインコンテスト（テーマ：「風」／B4ヨコ見開き：右＝表表紙・左＝裏表紙／JPEG 10MB以下）向けのコンセプト設計・5mラック視認性比較・ロゴ14パターン配置検証・実写B4トリミング書き出しWebスタジオです。

## v2.0 ゼロベース刷新の3作品（3640 × 2570 px / sRGB / 10MB以下）

2. **作品②『風がつくる余白』**（`assets/komebito7_v2_work2_yohaku.jpg` / 1.30 MB）
   - 新春1月号にふさわしい淡浅葱色の手漉き和紙の上に、手でちぎった純白和紙を幾重にも立体的に重ね、風が余分なものをさらって残す澄んだ「余白」と光を宿した白い繭粒を表現したペーパーレリーフ。
3. **作品③『夕凪のチェックイン』**（`assets/komebito7_v2_work3_yunagi.jpg` / 1.34 MB）
