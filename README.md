# komebito7-wind-cover — 『こめびと』第7号（テーマ：風）B4見開き表紙スタジオ

シマダグループ総合冊子『こめびと』第7号 表紙デザインコンテスト（テーマ：「風」／B4ヨコ見開き：右＝表表紙・左＝裏表紙／JPEG 10MB以下）向けのコンセプト設計・ロゴ配置検証・実写B4トリミング書き出しWebスタジオです。

## 主な機能

1. **B4見開きギャラリー＆ロゴ視認性シミュレーター（3作品）**
   - 第4〜6号の実物表紙レイアウト（表表紙上部中央の横書きロゴ・右上エンブレム・右端中段の縦書き巻頭エッセイ見出し）を重ねて視認性を検証できます（白抜きロゴ／墨ロゴ切替、B4見開き／B5表表紙単体プレビュー切替）。
   - 作品①『風選のあと、唇にのこる音』
   - 作品②『まだ家具のない部屋に、最初の風を通す』
   - 作品③『二千年の風名を、麻布の舟に積む』
2. **実写写真 → B4ヨコ（3640×2570px・10MB以下）JPEG書き出しスタジオ**
   - スマートフォンやカメラで撮影した実写写真を読み込み、ロゴ余白ガイドを見ながら位置・ズームを合わせ、ガイド線を含まない純粋なB4ヨコ比率（3640×2570px・10MB以下）のJPEG画像をブラウザ内（外部送信なし）で書き出せます。
3. **応募コメント文1タップコピー＆提出チェックリスト**
   - 各作品のコンセプトコメント文のワンクリックコピーと、提出仕様チェックを行えます。
